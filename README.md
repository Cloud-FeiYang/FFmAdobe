# Suzu — FFmpeg Exporter Plugin for Adobe Premiere Pro

<p align="center"><img src="assets/suzu.svg" width="120" alt="Suzu logo" /></p>

A native Premiere Pro exporter plugin (`.prm`) that pipes raw video and audio directly to FFmpeg for encoding, with a configurable **FFmpegFreeUI** front-end.

## Features

- **Zero intermediate files** — uses Windows named pipes to stream raw BGRA video and F32LE audio directly to a single FFmpeg process
- **Full Unicode path support** — `CreateProcessW` for CJK/special character output paths
- **FFmpegFreeUI integration** — dedicated tab in Premiere's export panel with a "Configure" button that launches the FFmpegFreeUI configuration tool
- **Preset pipeline** — FFmpegFreeUI presets (`.json`) are automatically converted to FFmpeg command-line arguments via PremierePresetConverter
- **Threaded audio pipeline** — audio rendering runs in a background thread, parallel with video frame piping
- **Automatic frame orientation fix** — `vflip` filter corrects Premiere's bottom-up BGRA buffer

## Architecture

```
Premiere Pro                       PremierePresetConverter
    │                                      │
    │  "Configure" button                  │  Converts FFmpegFreeUI
    │  → launches FFmpegFreeUI             │  full preset JSON → simplified JSON
    │  → user selects saved preset         │  (video_args, audio_args, filters...)
    │  → converter runs automatically      │
    │                                      ▼
    │                            %APPDATA%\Suzu\premiere_preset.json
    │                                      │
    ├─ Main thread (video frames)          │
    │     └──► \\.\pipe\ffmpeg_video_{PID}  │
    │                                    ╲ │
    └─ Background thread (audio)          ╲▼
          └──► \\.\pipe\ffmpeg_audio_{PID} ──► ffmpeg.exe ──► output file
```

## Requirements

- **Adobe Premiere Pro** 22.0+ (tested with 26.0)
- **Adobe Premiere Pro C++ SDK** (26.0)
- **FFmpeg** in system PATH
- **Visual Studio Build Tools** (MSVC)

## Build

```powershell
# Configure
cmake -B build -G "Visual Studio 18 2026" `
      -DADOBE_PP_SDK="E:/Code/Premiere Pro 26.0 C++ SDK"

# Build plugin
cmake --build build --config Release

# Build PremierePresetConverter
cd src/PremierePresetConverter
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

## Install

### Option 1: Installer (recommended)

Build and run the Inno Setup installer:

```powershell
cd installer
iscc Suzu.iss
# Output: installer/output/Suzu-26w21e-x64-Setup.exe
```

The installer provides:
- Component selection (Plugin / FFmpegFreeUI / Converter)
- Automatic registry configuration for plugin → FFmpegFreeUI path discovery
- Proper uninstaller with full cleanup (files, registry, user data)

### Option 2: Manual

Copy to `C:\Program Files\Adobe\Common\Plug-ins\7.0\MediaCore\Suzu\`:

```
Suzu.prm                     # Plugin
PremierePresetConverter.exe   # Preset converter
```

Place FFmpegFreeUI anywhere and set registry key:
```
HKLM\SOFTWARE\Suzu\FFmpegFreeUIPath = "C:\path\to\FFmpegFreeUI.exe"
```

## Preset Format

The plugin reads a **simplified JSON** (generated by PremierePresetConverter from FFmpegFreeUI's full preset):

```json
{
  "version": "1",
  "video_args": "-c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p",
  "audio_args": "-c:a aac -b:a 320k",
  "video_filters": "hqdn3d=luma_spatial=4",
  "audio_filters": "",
  "container": ".mp4",
  "extra_input_args": ""
}
```

Default (no preset configured): `H.264 CRF 18 fast + AAC 320kbps`.

## Syncing FFmpegFreeUI Upstream

The `FFmpegFreeUI/` directory is managed via **git subtree** (upstream: `https://github.com/Lake1059/FFmpegFreeUI.git`). **Zero modifications** are made to files inside this directory — all adapter code lives in `src/PremierePresetConverter/`.

```powershell
# Pull latest changes from upstream
git subtree pull --prefix=FFmpegFreeUI ffmpegfreeui main --squash

# If the remote is not configured:
git remote add ffmpegfreeui https://github.com/Lake1059/FFmpegFreeUI.git
```
